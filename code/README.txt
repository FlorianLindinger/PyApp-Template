APPLICATION SOURCE
==================

This folder contains the parts of the template that are normally customized
for an application.

START HERE
----------

- main.py: the application entry point.
- settings.py: project-specific settings imported by the application.
- backend/developer_settings.py: application name, Python version, and
  launcher-related settings.
- pyproject.toml: configuration for development tools.

FOLDERS
-------

- backend/dev_tools/: shortcuts for managing and checking the development
  environment.
- backend/icons/: application icon assets.
- backend/DONT_CHANGE/: portable launcher internals. Avoid editing these
  files unless you are maintaining the template itself; see its README.md.

Generated Python environments, installed packages, logs, and crash reports
are kept outside normal source control. See the repository README for setup
and first-run instructions.
