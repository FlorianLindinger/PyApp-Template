=======================================
==== HOW TO CHANGE ICONS ===============
=======================================

TL;DR
-----

1. Replace code/backend/icons/icon.png with the base image you want.
2. Optionally replace any overlay PNG in the same folder.
3. Run code/backend/icons/regenerate icons.lnk.

The generator creates multi-resolution .ico files in code/backend/icons/.
Do not rename the input PNG files.


=======================================
==== INPUT PNG FILES ===================
=======================================

Base image:

    icon.png

Optional overlay images:

    settings.png
    stop.png
    log.png
    success.png
    failure.png
    crash.png
    crash_log.png
    open_main_py.png
    keyboardInterrupt.png

Each overlay is placed on top of icon.png to create a matching .ico file.
For example, settings.png produces settings.ico.

If an input image is absent, or has not been changed from the template image,
the generator uses the matching bundled fallback from:

    code/backend/DONT_CHANGE/scripts/icon/

The bundled fallback files are named default_icon.png,
default_settings.png, default_stop.png, and so on (including
default_open_main_py.png and default_keyboardInterrupt.png).


=======================================
==== OVERLAY SETTINGS ==================
=======================================

Configure each overlay independently in:

    code/backend/developer_settings.py

Every overlay has two settings, for example:

    settings_sub_icon_scale: float | None = 0.35
    settings_sub_icon_alignment: str | None = "bottom right"

Scale is the fraction of the base icon area covered by the overlay. It must be
greater than 0 and at most 1. Alignment accepts compass-style positions such
as "bottom right", "top", "center", or "center left".

Set either setting in a pair to None to generate that .ico without its overlay.


=======================================
==== GENERATION ========================
=======================================

Run:

    code/backend/icons/regenerate icons.lnk

This launches scripts/icon/generate_icons.py with the bundled backend Python. It creates:

    icon.ico
    settings.ico
    stop.ico
    log.ico
    success.ico
    failure.ico
    crash.ico
    crash_log.ico
    open_main_py.ico
    keyboardInterrupt.ico

Each ICO contains 256, 128, 64, 48, 32, and 16 pixel versions for good
appearance in Windows shortcuts, Explorer, and the taskbar.

The generator uses built-in Windows PowerShell/WPF and does not require Pillow.
It caches repeated image checks and generates several independent icons at once
to reduce regeneration time.


=======================================
==== PLACEHOLDER PNGS ==================
=======================================

To create readable placeholder PNGs with instructions, run:

    code/backend/DONT_CHANGE/scripts/icon/generate_PNGs_to_be_replaced.py

The files are written to:

    code/backend/DONT_CHANGE/icon_related/created_PNGS_to_be_replaced/

Copy a generated placeholder to code/backend/icons/ only when you want it to
become an editable input image. PNG size, colors, font, and placeholder text
are configured in backend/DONT_CHANGE/settings/backend_settings.py.
