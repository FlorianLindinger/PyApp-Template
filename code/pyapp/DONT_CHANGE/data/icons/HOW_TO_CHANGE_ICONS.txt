=======================================
==== HOW TO CHANGE ICONS ===============
=======================================

TL;DR
-----

1. Replace code/pyapp/icons/icon.png with the base image you want.
2. Run code/pyapp/icons/regenerate icons.cmd.

The generator creates multi-resolution .ico files in code/pyapp/icons/.
Do not rename icon.png.

To use your own icon for one case, replace that .ico file directly, for
example failure.ico (see "Replacing one icon" below).


=======================================
==== BASE IMAGE ========================
=======================================

    icon.png

If it is absent, or has not been changed from the template image, the generator
uses default_icon.png from:

    code/pyapp/DONT_CHANGE/data/icons/


=======================================
==== OVERLAYS ==========================
=======================================

Every icon except icon.ico is the base image with a small overlay on top. The
overlay images are bundled in the folder above and cannot be replaced with a PNG.

Each overlay's size and position are in SUB_ICONS in:

    code/pyapp/DONT_CHANGE/backend_settings.py

For example:

    "settings": (0.35, "bottom right"),

Scale is the fraction of the base icon area covered by the overlay. It must be
greater than 0 and at most 1. Alignment accepts compass-style positions such
as "bottom right", "top", "center", or "center left".

Use None instead of the pair to generate that .ico without its overlay.


=======================================
==== REPLACING ONE ICON ================
=======================================

Replace any .ico file in code/pyapp/icons/ with your own, keeping its name:

    icon.ico
    settings.ico
    stop.ico
    log.ico
    success.ico
    failure.ico          (also shown after a crash or Ctrl+C)
    crash_log.ico
    open_code.ico

The generator remembers which icons it made, in
code/pyapp/generated/auto_generated_icons.json (commit that file with the icons). Those
update without a question. For an .ico you placed yourself it asks, per icon, before
replacing it; answer no to keep yours. To go back to the generated icon, answer yes
or delete your .ico and regenerate. Run Setup again so that shortcuts show the new icon.


=======================================
==== GENERATION ========================
=======================================

Run:

    code/pyapp/icons/regenerate icons.cmd

The launcher reports success or failure and waits for a keypress before closing.
It works after moving the project folder because its paths are relative to itself.

Each ICO contains 256, 128, 64, 48, 32, and 16 pixel versions for good
appearance in Windows shortcuts, Explorer, and the taskbar.

The generator uses built-in Windows PowerShell/WPF and does not require Pillow.
